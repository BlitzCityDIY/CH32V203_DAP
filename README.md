# CH32V203_DAP

CMSIS-DAP SWD programmer Arduino library for the WCH CH32V203, developed on the
Adafruit QT Py CH32V203.

## Wiring (QT Py -> target)

| QT Py | Target |
|---|---|
| A3 (PA0) | SWDIO |
| A2 (PA1) | SWCLK |
| A0 (PB1) | nRESET (optional) |
| GND | GND |
